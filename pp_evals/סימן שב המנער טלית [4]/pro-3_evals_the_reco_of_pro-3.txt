להלן ניתוח האיכות של פלט המודל מול תשובת האמת (GT):

### ניתוח טקסטואלי

**1. כותרות (Headlines):**
המודל זיהה 2 מתוך 4 הנושאים (מחלוקות) המופיעים ב-GT.
- **הצלחה:** "ממה מנערה?" (GT) תואם ל"מהו הניעור האסור?" (Model). כמו כן, "מתי נקראת טלית חדשה?" (GT) תואם ל"מהי הגדרת בגד חדש?" (Model).
- **כישלון:** המודל החמיץ לחלוטין את הנושאים של "תנאי האיסור" (חדשה, שחורה, מקפיד) ו"הגדרת הקפדה".
- **הזיות:** המודל המציא שני נושאים חדשים שלא מופיעים כנושאים נפרדים ב-GT: "מה הטעם שהאיסור..." ו-"משום איזו מלאכה חייב...".
- **ציון כותרות:** ממוצע של: 100, 0, 100, 0 = **50**.

**2. קטגוריות (Categories):**
- **TP (זוהו נכון):** המודל זיהה את קטגוריות "טל" ו-"עפר" (בנושא הניעור), ואת קטגוריות "שלא כובס" ו-"כמו שיצא מהאומן" (בנושא הגדרת חדש). סה"כ **4**.
- **FP (הומצאו/לא ב-GT):** המודל יצר קטגוריות עבור הנושאים שהמציא (טעמים ומלאכות) - סה"כ **4** קטגוריות מיותרות.
- **FN (פספוסים):** המודל פספס את קטגוריית "הצהוב הלבן" (בנושא הניעור), ואת כל 4 הקטגוריות בנושאים שהוחמצו (תנאים והגדרת הקפדה). סה"כ **5**.

**3. דעות ושרשראות (Opinions chains):**
הבדיקה נערכה רק בתוך הקטגוריות שזוהו (טל, עפר, הגדרות חדש).
- **TP (שרשראות מדויקות):**
  1. `בית יוסף >> רש"י` (בנושא עפר).
  2. `בית יוסף >> ה"ה >> רשב"א` (זוהה כ- `בית יוסף >> רב המגיד >> רשב"א`).
  3. `בית יוסף >> ראב"ד`.
  4. `בית יוסף >> רמב"ם` (בנושא אומן).
- **FP (שגיאות מבניות/תוכן):**
  1. השרשרת `בית יוסף>>תוספות, רא"ש, ר"ן, מרדכי>>רבנו חננאל` – שגיאה מבנית חמורה. המודל איחד מקורות נפרדים ב-GT ויצר שרשרת בה כולם מצטטים את ר"ח (בעוד ב-GT הם מובאים כדעות עצמאיות או הסכמות). נחשב כשרשרת שגויה אחת.
  2. השרשרת `בית יוסף>>משמעות לכאורה` (במקום `בית יוסף` בלבד). המודל הפך את המילה "משמע" לחוליה בשרשרת ("משמעות לכאורה"), מה שמהווה "חוליה מיותרת" לפי הכללים הקפדניים.
- **FN (חסרים):**
  מתוך 8 שרשראות בקטגוריית "טל" ב-GT, המודל דייק רק ב-2. בנוסף חסרה שרשרת אחת בנושא "חדש". סה"כ **7** חסרים.

### חישוב ציונים

1.  **כותרת:** (100 + 0 + 100 + 0) / 4 = **50**
2.  **דיוק קטגוריות (Precision):** 4 TP / (4 TP + 4 FP) = **50%**
3.  **כיסוי קטגוריות (Recall):** 4 TP / (4 TP + 5 FN) = 4/9 = **44%**
4.  **דיוק דעות (Precision):** 4 TP / (4 TP + 2 FP) = 4/6 = **67%**
5.  **כיסוי דעות (Recall):** 4 TP / (4 TP + 7 FN) = 4/11 = **36%**
